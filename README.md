## AboRechner - Subscription Cost Calculator

## Description

A simple C# console application that calculates the total cost of a subscription based on its monthly price and duration.

## Features

 - Accepts a monthly subscription price and the number of months.
 - Validates user input.
 - Calculates the original subscription cost.
 - Applies a 10% discount for subscriptions of 12 months or longer.
 - Displays the original price, discount amount and total price.

## Example

**Input:**
- monthly price: 20 EUR
- Duration : 12 months

**Output:**

- Original price: 240 EUR
- Discount amount : 24 EUR
- Totalprice : 216 EUR

## Technologies

- C#
- .NET
- Console Application

## Purpose

This project was created to practice basic C#-programming concepts, including variables, conditional statements, calculations and input validation.
